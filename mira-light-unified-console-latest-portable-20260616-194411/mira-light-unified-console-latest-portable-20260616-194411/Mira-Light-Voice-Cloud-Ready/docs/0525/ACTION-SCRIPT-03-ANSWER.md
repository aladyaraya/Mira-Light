核心要求：**每个语义点必须拆成预备、强调、回弹；不能一个词一个 pose 硬跳**

## 0. 当前稀疏 timeline 的问题

当前 `voice_motion_demos.py` 里 answer 已经有很多 marker，但执行逻辑仍然是：

```text
到时间点 -> Popen pose
到下个时间点 -> Popen pose
```

如果相邻点差值大、缺少中间补间，就会出现：

```text
一卡一卡
一步到位
像机械打点，不像说话
```

Answer 要按口播语义做动作簇：

```text
语义预备 0.08-0.16s
主强调 0.12-0.22s
回弹 0.10-0.20s
短停顿 0.08-0.30s
```

音频延迟：

```text
board_t 0.00: 动作先启动
board_t 0.40: 音频开始
audio_t = board_t - 0.40
```

## 5. 为什么这版更灵动

每个重点词都不是一个姿态，而是一个动作簇：

```text
“Big meets Little”
prep left -> left -> rebound

“超萌绘本”
prep down -> lift -> rebound

“又暖又好笑”
pause down -> launch half -> punch up -> rebound -> laugh swing
```

这才像在说话。  
稀疏 timeline 只是在打点。

## 6. 时间对齐方式

这份脚本是动作片段，不是绝对时间表。接入音频时有两种方式：

### 方式 A：按顺序跑

适合先调动作质感。  
优点是自然，不卡。缺点是需要微调总时长。

### 方式 B：按音频 anchor 调整 hold

把每个语义簇对齐到音频：

| 音频段 | 对应动作簇 |
| --- | --- |
| 0.00 “En” | `en front` |
| 0.5 “Big meets Little” | `book name left` |
| 1.0 “刘扬” | `author right` |
| 2.0 “超萌绘本” | `cute lift` |
| 3.8 句号 | `period lower` |
| 4.2 “极简图标” | `second sentence open` |
| 7.6 “又暖又好笑” | `punch up` |
| 8.0 笑点后 | `laugh right/left` |
| 9.0 最后一句 | `final sentence open` |
| 11.8 “哦~” | `ending cute` |

## 7. 调参规则

如果还是卡：

```text
1. 相邻 pose 差值超过 160 的地方加中间 pose
2. 每个强动作后必须有 rebound
3. P1/P2 speed 降低 15%
4. hold 不要全是 0.4s，大多数小段应在 0.08-0.22s
```

如果不够迅速：

```text
1. 只提高强调点 speed，不提高全部 speed
2. P0/P3 可快，P1/P2 慎重
3. punch/laugh 用 0.08-0.16s 短 hold
```

如果不够灵动：

```text
1. 增加 P3 回弹
2. 每个主动作前做反向预备
3. 左右摆后不要直接回中，加半回弹点
```

## 8. 安全边界

短促强调可以接近高位，但不要长时间 hold。

建议上限：

```text
P0: 1850-2250
P1: 2130-2350，短促可更高但不建议长 hold
P2: 1900-2200，按姿态联动微调
P3: 1980-2280
```

如果现场机械声音变尖、颈部发热、动作变慢：

```text
立刻降低 P1/P2 幅度
减少 punch 和 laugh 次数
让它回 NATURAL
```

## 9. 验收标准

- “又暖又好笑”必须是全段最明显动作。
- 所有大动作都有预备和回弹。
- 观众看不到明显一帧一帧跳。
- 说话时身体节奏跟台词同步，而不是均匀摇摆。
- 结尾自然回到 `2048 2150 2048 2130` 附近。
