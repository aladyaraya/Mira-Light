# Mira Light — 更新日志（2026-06-26 ~ 2026-06-28）

## 概述

在 Windows 11 (Python 3.14) 下完成 Mira Light 系统完整调试与深度优化。
核心成就：语音控制从"不可用"优化到"稳定实时响应"，40+ 动作命令本地毫秒级匹配。

## 一、Web 控制台修复

- `shenzhen_console.py:1603` — Windows 禁用 ControlMaster（避免 `getsockname failed`）
- `~/.ssh/config` 添加 `Host 192.168.0.183`，IP 直连也走密钥

## 二、语音全链路打通

### 引擎选择
| 引擎 | 文件 | 特点 |
|------|------|------|
| **stepfun-realtime**（当前使用） | `mira_stepfun_realtime_voice_actions.py` | StepAudio 2.5，自然女声 TTS |
| legacy-full | `mira_realtime_voice_interaction.py` | Lingzhu 云端对话，需额外 Key |

### 动作→硬件链路
```
麦克风 → StepAudio ASR (0.8s) → 本地意图匹配 (0s) / LLM 规划
  → 动作桥 19783 → tcp://192.168.0.183:9527 → 舵机/LED
```

### 延迟精简
| 优化点 | 优化前 | 优化后 |

## 六、已知局限

1. **灯光命令**（"开灯"/"关灯"/"暖光"）本地不匹配，走 LLM 回退（慢），需后续加入 LED 意图
2. **板端 9527** 非自启，断电需手动重启
3. **Edge-TTS** 被墙，当前使用 StepAudio 内置 TTS
4. **Python 3.14 venv** pip 初始化有问题，建议用 Python 3.12
