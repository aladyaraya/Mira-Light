# Mira Light Unified Director Console Keyboard Variant

这个变体控制台复用原 `mira-light-unified-director-console` 后端能力，
只替换前端页面，在舵机区域追加了轨迹录制 / 回放面板。

默认启动方式：

```text
Start-Mira-Light-Unified-Director-Console-Keyboard.command
```

默认地址：

```text
http://127.0.0.1:8791/
```

可覆盖环境变量：

```text
MIRA_UNIFIED_WEB_ROOT=/path/to/custom/web
MIRA_UNIFIED_CONSOLE_PORT=8791
```
